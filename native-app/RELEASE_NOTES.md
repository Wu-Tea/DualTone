# DualTone v0.4.0 · 双路同步

新增可选的双路同步：通过已有虚拟音频入口分别输出到主音箱和副设备，主路可增加 0–1000 ms 延迟，保留原来的直出模式。

- 主音频旁打开「同步设置」，选择入口、数字输入或滑条调节主路延迟；支持播放中调整。
- 主路不经过副路 EQ、增益和混响，静音对比仍只控制副路；两路独立事件渲染和有界时钟校正。
- 正常停止、退出或音频错误后恢复仍由应用占用的默认输出；不覆盖用户手动更改的输出，通信角色不变。
- GUI、CLI、持久配置支持新参数。配置升级到 version 4，读取 version 1–3 并保留迁移备份；升级默认保持直出。
- 声音预设和导入保留当前路由与主路延迟，避免预设意外重定向系统声音。

需要已经安装的虚拟声卡；不包含新驱动、模型或大型运行环境。包体继续限制在 20 MiB。主路延迟是手动补偿值，不是自动声学测量。被强制结束时需在 Windows 中重新选择物理音箱。应用未作代码签名。
