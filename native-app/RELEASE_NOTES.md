# DualTone v0.5.0 · 统一界面

参考用户指定项目的材质分层与控件规范，重做原生 GUI，继续保留轻量 C++ / Slint 架构和全部音频处理、双路同步及 CLI 功能。

- 主面板收为 460×510：选设备、调副音量、选效果和预设。音效参数、频谱和过滤集中到声音调节，队列和电平移到诊断；运行错误仍就地显示。
- 深灰底色、浅蓝选中态、统一表面与数值控件；EQ、同步、预设、菜单和确认窗口使用同一套规范。外观提供深色、浅色、跟随系统，独立持久化。
- 参数可用滑条或数字精确编辑；下拉菜单支持方向键、回车和 Esc，数字框宽度不随数值变化。
- 预设操作集中管理，补齐更新与重命名；更新/删除先确认，声音预设不会改动设备路由或主路延迟。
- CLI 新增 `preset-update NAME`、`preset-rename OLD NEW` 和 `appearance [dark|light|system]`，在线与离线均可使用。

配置继续使用 version 4，已有音频参数和预设保留。外观为 `data/appearance.json`；无浏览器运行时、图像模型或新增音频驱动。运行包继续限制在 20 MiB 内。程序未作代码签名。
