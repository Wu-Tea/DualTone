# DualTone v0.3.0 · 副路混响

新增“副路混响”模式：主音频直出，副音频只播放混响尾音。空间补充模式、旧声音参数及全部 CLI 命令保留。

- 主面板直接切换模式，调节空间大小、尾音时长、明暗和副路音量；切换平滑过渡。
- 轻量八路 FDN 混响，削减输入低频，高频阻尼可调；源流停止后继续输出尾音。
- GUI 修正设备标题缩进、图标和按钮垂直居中、图例对齐以及频段增益标签。
- 新参数随预设保存；CLI schema 提供范围和单位。混响模式拒绝把反射时间当成普通转发延迟。
- 配置升级为 version 3，读取旧配置后默认保持空间补充；首次保存保留旧版本备份。
- 修复命名管道提前断开导致客户端偶发收不到响应的问题，增加延迟读取回归测试。

运行版不需要新运行环境或模型，完整 ZIP 继续限制在 20 MiB 以内。旧版配置请直接保留，程序启动不自动启用混响。回退旧程序时使用迁移前的备份。

验证包括无直达声、立体声尾音、衰减/大小参数、实时改参、分包一致性、GUI 点击与 CLI 联动、预设及配置迁移、原有 DSP 数值对照和真实音频端点。混响不是人声分离、和声生成或 5.1；不会给主音频增加延迟。应用未作代码签名。
