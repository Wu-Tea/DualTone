# DualTone v0.5.4 · 不同采样率共播

修复 384 kHz 小尾巴被误判为不支持、无法与 48 kHz 显示器一起使用的问题。

- 新增 352.8 和 384 kHz 双向重采样，设备保留各自的 Windows 音频格式。
- 采用已有的因果 FIR 抗混叠滤波，保持音高、时长和左右声道；不直接丢点或裁剪整段声音。
- 主音频继续直出，Windows 音量键照常控制物理主设备。仅副音频经过重采样和声音处理。
- 设备选项显示采样率；CLI schema 提供支持的采样率及处理格式。
- 采样率清单与滤波器表从同一来源生成，避免支持列表和实现脱节。

不同采样率共播不等于声学零延迟同步，设备内部和无线延迟仍可能存在。已有声音参数和预设保留。
