# DualTone v0.2.0 · 原生轻量预览版

将 v0.1 的 Python / Qt / NumPy / SciPy 运行环境替换为 C++ 原生音频核心和 Slint Fluent UI，保留 GUI、JSON CLI、旧配置与预设格式。

完整免安装 ZIP 约 **15.3 MiB**，解压约 **31.9 MiB**；包含必要运行库、许可证和原生源码，无需额外下载安装运行环境。

- 紧凑主面板、独立声音调节窗口、深浅主题、实时频谱与托盘。
- 图上十段 EQ、数值输入、增益归零、可增删的多段过滤。
- 空间补充、主体保留、副路音量、静音对比。
- 主副设备选择、交换、刷新和运行中副路切换。
- 预设增删、导入导出、本机音效检查、数字延迟测量。
- GUI 与 CLI 共用原生核心和命名管道，独立 CLI 不加载界面框架。

原生 DSP 对照包含默认、截图 EQ、窄频段、多段混合、旁通、关闭全部段和旧原声模式。支持采样率的全部输入/输出组合通过分包数值对照；GUI/CLI 共享状态、预设、旧配置与管道名称兼容检查通过。真实 96→48 和 96→96 kHz 转发以零增益测试，默认输出保持不变。

解压后运行 DualTone.exe，保留同目录 DLL。升级可复制旧版 data 文件夹，先退出旧实例。新包不携带个人配置。

蓝牙的无线和设备内部延迟依然存在，不承诺与有线音箱同步；不会给主音频加延迟。空间补充不是 AI 人声去除或真正的 5.1。应用未作代码签名。
