# DualTone v0.5.2 · 主音频直出与统一标题栏

撤回虚拟声卡双路同步，恢复 Windows 直接播放主音频。新版精简 UI、原生音频核心和 CLI 保留。

- 系统默认输出回到物理主设备，Windows／键盘音量继续控制主音频；应用不再转发或延迟主路。
- 移除 GUI 的同步设置入口，CLI 明确拒绝开启 sync。旧版同步配置加载为 direct，副路参数及预设保留，首次写入前保留原文件备份。
- 首页恢复可调参数：空间补充可调中心声量，混响可调尾音时长；完整音效、EQ 和频段仍在声音调节中。
- 所有窗口使用统一标题栏，提供最小化、最大化／还原和关闭；保留拖动、边缘缩放及双击标题栏操作。
- 新增双声波应用图标与仅在“关于”中显示的声场插图，直接嵌入原生程序。
- 不自动改动用户的音量、EQ、频段或空间强度。曾在播放器内固定选择虚拟声卡的用户需将播放器改回系统默认或物理主音箱。

原生免安装包，未添加驱动或运行时；未做代码签名。
